# Семинар 6. Очередь отложенных вызовов на базе проекта [семинара 5](https://github.com/gregkorneev-BMSTU/s2_sem5)

Проект продолжает банковскую предметную область из семинара 5. Поверх уже существующих классов добавлена очередь отложенных вызовов `PendingQueue`, которая умеет сохранять функции и методы вместе с аргументами, а затем выполнять их позже по одной или все сразу.

## Что такое очередь отложенных вызовов

`PendingQueue` - это объект, который:

- принимает задачу через `enqueue(...)`;
- не выполняет ее сразу;
- хранит задачу в очереди;
- запускает одну задачу через `run_one()`;
- запускает все оставшиеся задачи через `run_all()`;
- в деструкторе сообщает, сколько задач было удалено без выполнения.

## Что показывает программа

После запуска программа:

- создает банк, клиента и счета из семинара 5;
- создает `PendingQueue`;
- добавляет в очередь обычную функцию логирования;
- добавляет в очередь метод `Bank::addDepartment`;
- добавляет в очередь метод вывода состояния;
- добавляет банковские операции `deposit`, `transfer`, `addMonthlyInterest`, `unlock`, `withdraw`;
- сначала показывает, что после `enqueue(...)` задачи еще не выполнились;
- затем демонстрирует `run_one()` и `run_all()`;
- отдельно показывает уничтожение очереди с невыполненными задачами.
